Which research agent still tells the truth when the world changed last week?

Every agent gets the same time-sensitive questions, the same model through a self-hosted Bifrost gateway and the same Tavily search tool, repeated under injected faults. Answers are graded for the current fact and audited claim-by-claim by the Stale-Answer Detector. Ranking uses the lower bound of a 95% Wilson interval, so one lucky run can't win.

Paste any LLM answer. Bifrost extracts the claims and flags the time-sensitive ones, Tavily re-checks each against the live web, and every claim gets a verdict, a freshness score and its sources. Evidence (what the sources say) is shown apart from inference (what the model concluded).

Bifrost does

  • One OpenAI-compatible endpoint, so agents need no changes
  • Fallback chain that rescues runs when the primary provider is down
  • Routing info per call: which model really answered
  • Harness virtual key with a daily USD budget
  • All detector reasoning calls

Tavily does

  • The live search & extract tool every agent uses
  • Fresh evidence the detector checks each claim against
  • Ground-truth drift checks for the task suite
  • Cached per query so repeats see the same evidence and spend credits once
